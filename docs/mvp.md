# Скоуп MVP

Зафиксировано 22 ноября 2026. Это граница первого рабочего среза. Всё, чего в этом файле нет, в MVP не входит.

## Вход

На вход попадает видео матча.

Другого входа нет. Tekken ID, шапка матча, файл реплея, память клиента и ручная разметка обмена видео не заменяют.

## Что делает приложение

По ролику, по порядку:

1. Распознаёт персонажей: кто стоит с каждой стороны.
2. Распознаёт удары: какой удар делает каждый из них.
3. Подгружает свойства этих ударов из каталога того персонажа, которого назвал ролик.
4. По взаимодействию персонажей делает вывод: это правильно или ошибка.

Свойства — то, что у удара уже записано в каталоге: стартап, на каких кадрах он бьёт, что даёт на блоке и на попадании, высокий он, средний или низкий. С полоски здоровья и из счёта раунда свойства не читаются.

Взаимодействие — как удары сошлись в этом месте ролика: попадание, блок, промах и чей после этого ход. Вывод строится из этого стыка и из подгруженных свойств. Победа раунда, урон и сам факт попадания вывод не делают.

Пока персонаж или удар не распознан, свойства подгружать не к чему и вывода нет. Приложение не достраивает пропущенный удар.

## Чего в MVP нет

- Разбор обмена, который размечен руками, без видео.
- Список матчей по Tekken ID и загрузка шапки.
- Мод, память клиента и журнал вводов как дверь в базу.
- Правка пола, черновик из нескольких матчей, привычка игрока, фильтр кнопки.
- Движение, которое ударом не является: дашблок, KBD, сайдстеп. MVP читает удары.
- Целый гамеплан и сверка с каноном раунда. Вывод этого среза — правильно или ошибка на одном взаимодействии.

## Когда срез собран

На видео матча приложение называет обоих персонажей, называет их удары, показывает подгруженные свойства и на каждом разобранном стыке ставит «правильно» или «ошибка». Нераспознанный персонаж или удар остаётся без вывода.
