# couch

Приложение сверяет твой обмен в Tekken 8 с полом Reina, который уже записан. Победа обмена, урон и счёт раунда couch не двигают. Попавший hellsweep с плюса остаётся ошибкой, если пол его не назвал. Заблокированный `df+1` в красной зоне остаётся верным решением, пока зону не контрят.

Концепт лежит в [notes/replay-judge.md](https://github.com/LuckyHound94/tekken8-evo-japan/blob/main/notes/replay-judge.md). Этот срез — первый кусок из того порядка: couch на обменах, которые размечены руками.

## Что уже судит

У обмена четыре исхода: совпало, не совпало, не разобрано, исполнение.

Пустая дистанция даёт «не разобрано» и остаётся без совета. Если число закрытых лоу меняет слой, а на записи его не видно, hellsweep тоже остаётся неразобранным, пока число не поставишь ты. Роут после `ws3,4` читается и без дистанции: чужой следующий ввод — исполнение. WGF на месте electric — туда же.

Чужой персонаж в списке виден и в разбор не идёт. Реплей другого патча в уверенную ошибку паниша не идёт.

Правка одной ситуации показывает, сколько старых строк она перевернёт, и после подтверждения судит сразу. В файл базы она не пишет: готовит фразу. Привычка одного игрока — счётчик, общий пол от неё не меняется.

Черновик собирается только из разобранных обменов. Частая дорогая кнопка в разрешение не предлагается.

## Чего в этом срезе нет

Живой список Wavu, мод у клиента и разбор видео. Шапка 11 октября 2026, Reina против Alisa, открывается пустой: файл старше патча 3.03.01. Пол в коде — срез канона, не весь файл решений. Паника в пок одной кнопкой не закрыта: пол её так не назвал.

## Запуск

```bash
npm install
npm test
npm run dev
```

Учебный матч и правки лежат в браузере, ключ `tekken-couch.v1`. «Вернуть учебный набор» стирает их на этом устройстве. Файл couch скачивается и загружается обратно с экрана «couch».
