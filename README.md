# couch

MVP принимает видео матча. Приложение распознаёт персонажей и удары, подгружает свойства ударов и по их взаимодействию говорит, правильно это или ошибка.

Скоуп зафиксирован в [docs/mvp.md](docs/mvp.md).

## Что уже лежит в репозитории

Экран «Видео» делает первые два пункта скоупа. Ролик открывается с диска или по ссылке на YouTube. Если сам файл ролика не открывается, читаются кадры превью. Приложение находит полоски здоровья и читает имя у портрета слева и справа. Надпись сверяется со всем ростером. Если по ходу ролика стороны меняются, оно показывает отрезки. Под именем оно читает строки ударов и отдаёт их каталогу на бэкенде. Каталог хранит команды ударов того персонажа, которого ролик уже назвал, и не хранит свойства кадра. Удар называется, только если команда есть у этого персонажа. Строка, которую не удалось прочитать, остаётся без имени: соседнее имя, похожая буква и пропущенный удар его не достраивают. Движение без удара в список не попадает.

Свойства удара и вывод «правильно или ошибка» этот шаг не делает. Команды сверены по срезу tekkendocs.

Рядом в репозитории лежит прежний срез: обмен размечен руками, и приложение сверяет его с полом Reina. Это не MVP. Экраны «Матчи», «Матч» и «couch» его не прячут.

```bash
npm install
npm test
npm run dev
```

Учебный матч и правки лежат в браузере, ключ `tekken-couch.v1`.
