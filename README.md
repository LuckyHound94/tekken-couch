# couch

MVP принимает видео матча. Приложение распознаёт персонажей и удары, подгружает свойства ударов и по их взаимодействию говорит, правильно это или ошибка.

Скоуп зафиксирован в [docs/mvp.md](docs/mvp.md).

## Что уже лежит в репозитории

Экран «Видео» делает первый пункт скоупа. Ролик открывается с диска или по ссылке на YouTube. Приложение находит полоски здоровья и читает имя под портретом слева и под портретом справа. Если по ходу ролика стороны меняются, оно показывает отрезки. Строка, которую не удалось прочитать, остаётся без имени: соседнее имя и похожая буква его не достраивают.

Удары, свойства и вывод «правильно или ошибка» этот шаг не делает.

Рядом в репозитории лежит прежний срез: обмен размечен руками, и приложение сверяет его с полом Reina. Это не MVP. Экраны «Матчи», «Матч» и «couch» его не прячут.

```bash
npm install
npm test
npm run dev
```

Учебный матч и правки лежат в браузере, ключ `tekken-couch.v1`.
