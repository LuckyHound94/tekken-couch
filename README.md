# couch

MVP принимает видео матча. Приложение распознаёт персонажей и удары, подгружает свойства ударов и по их взаимодействию говорит, правильно это или ошибка.

Скоуп зафиксирован в [docs/mvp.md](docs/mvp.md).

## Что уже лежит в репозитории

Сейчас в коде другой срез: обмен размечен руками, и приложение сверяет его с полом Reina. Это не MVP. Видео он не читает, персонажей и удары с картинки не распознаёт.

```bash
npm install
npm test
npm run dev
```

Учебный матч и правки лежат в браузере, ключ `tekken-couch.v1`.
